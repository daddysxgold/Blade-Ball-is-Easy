Blade Ball script with the Rem v6.1 menu (Matcha)

1. Put rem_v6.lua in your Matcha workspace folder: C:\matcha\workspace\
   (replace the old rem_v6.lua if you have one)
2. Run "BB Source (Rem UI).lua" in Matcha.

Right Shift opens and closes the menu. You can change the key in Settings.

Scrolling: click and drag anywhere on empty space in a list to scroll it,
or drag the scrollbar on the right, or use Page Up / Page Down.
Dropdown lists scroll the same way. The mouse wheel also works if Matcha sends it.

Settings > Background lets you pick Rimuru, Rem, Crimson, Forest or None.
